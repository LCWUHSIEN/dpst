# 結帳系統串接 Google Sheet

```
瀏覽器（結帳表單）
   │  POST JSON（text/plain，避免 CORS 預檢）
   ▼
Google Apps Script 網頁應用程式（Code.gs）
   │  1. 驗證欄位、honeypot 防機器人
   │  2. 以「菜單」工作表的價格重新計算金額（不信任前端金額）
   │  3. LockService 加鎖 → 產生訂單編號 GTyyMMdd-001 → 寫入試算表
   │  4. requestId 去重（網路重試不會重複建立訂單）
   │  5. 寄通知信給店家 / 確認信給顧客
   ▼
Google Sheet：訂單／訂單明細／菜單
```

## 部署步驟（約 10 分鐘）

1. 建立一份新的 Google 試算表，命名例如「焙香鍋貼訂單」。
2. 選單 **擴充功能 → Apps Script**，把 `Code.gs` 全部貼上；
   左側 **專案設定** 勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」，貼上 `appsscript.json`。
3. 修改 `CONFIG.OWNER_EMAIL` 為店家收單信箱（留空則不寄信）。
4. 在編輯器上方選擇函式 `setup`，按 **執行**，並依畫面授權。
   會建立「訂單」「訂單明細」「菜單」三個工作表、狀態下拉選單與顏色標示。
5（選用）執行 `installTriggers`，每天早上 8 點寄出前一天營收摘要。
6. **部署 → 新增部署作業 → 類型選「網頁應用程式」**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   按「部署」並複製以 `/exec` 結尾的網址。
7. 打開 `index.html`，把網址貼到：
   ```js
   var ORDER_API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
   ```
   儲存、推送到 GitHub，網站就會真正送出訂單。留空則維持展示模式。
8. 瀏覽器直接開啟該 `/exec` 網址，看到 `{"ok":true,...}` 代表部署成功。

## 日常使用

- 新訂單出現在「訂單」工作表，狀態預設「新訂單」，用下拉選單改為「製作中 / 已完成 / 已取消」，「狀態更新時間」會自動記錄。
- 品項明細在「訂單明細」，用訂單編號對應。
- **改價格、下架商品：** 直接改「菜單」工作表的單價，或取消勾選「供應中」，不用動網站程式。新增品項時，代碼必須與網站 `index.html` 中的品項 id 一致。
- **修改程式後必須重新部署：** 部署 → 管理部署作業 → 編輯 → 版本選「新版本」，網址不會變。

## 注意事項

- 網址一旦公開，任何人都能對它送出請求；伺服器端已驗證欄位與金額、限制數量並加上 honeypot，但並非完整的防濫用機制。若遇到大量垃圾訂單，可再加入驗證碼或頻率限制。
- 試算表含顧客姓名、電話、地址，請只分享給需要的人，不要設為「知道連結的人都能檢視」。
- Apps Script 的寄信有每日額度（一般 Gmail 帳號約 100 封／日）。
- 本流程只記錄訂單，不處理金流。
